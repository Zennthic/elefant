# Getting help

- **Questions, setup help and ideas:** [GitHub Discussions](https://github.com/Zennthic/elefant/discussions).
  Check [TROUBLESHOOTING.md](TROUBLESHOOTING.md) first; it covers the common failures.
- **Bugs and feature requests:** [open an issue](https://github.com/Zennthic/elefant/issues/new/choose).
- **Security vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes. Never in a public issue or discussion.
